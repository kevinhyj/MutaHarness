# 谁每天在做这些事？

场景：一家做蛋白药物、酶或生物制造的研发团队。它的工作循环是**设计 → 制备 → 测试 → 学习 → 再设计**。计算团队决定下一批值得测试的突变，实验团队检验真实效果。

这里按职责归纳四类真实岗位。小团队中同一人可能兼任。公开依据包括 [Cradle 的实验与计算科学家工作流](https://www.cradle.bio/)、[其湿实验室与自动化介绍](https://www.cradle.bio/lab)、[Novonesis 的研发岗位](https://www.novonesis.com/en/careers/areas-of-work/research-and-development)。**下列时间比例是用于本任务的典型周工作估计，每个岗位合计 100%；不是企业工时调查，也不是某位员工的实际记录。** Query 是代表性需求，input 是示例输入包。

## 1. 蛋白工程科学家：决定改什么、为什么改

| 时间 | 任务 / 场景 | 代表性 query | input |
|---:|---|---|---|
| 25% | 读文献、定义目标与约束 | “把这个酶的优化目标转成可测指标，列出可能冲突的性质。” | 目标反应、温度/pH范围、现有性能、3篇机制论文 |
| 35% | 选择突变与设计候选库 | “只能测一块96孔板，优先选哪些突变？给出依据和风险。” | WT序列、候选突变、结构、MSA、实验预算 |
| 25% | 解释本轮结果、设计下一轮 | “哪些失败更像表达问题，哪些更像功能受损？下一轮如何区分？” | 表达量、活性、稳定性、重复实验、上一轮预测 |
| 15% | 跨团队评审与实验交接 | “把候选列表整理成实验员可以核对的设计单。” | 突变编号、参考序列版本、构建设计、优先级 |

## 2. 计算生物学 / ML 科学家：把证据变成预测

| 时间 | 任务 / 场景 | 代表性 query | input |
|---:|---|---|---|
| 25% | 整理序列、结构与实验数据 | “检查这些文件是否指向同一个蛋白，统一残基编号。” | FASTA、PDB、A2M、实验CSV、元数据 |
| 35% | **零样本 fitness prediction** | “没有本项目实验标签，给这批突变排出功能优先级。” | WT、候选、结构、MSA；不含fitness标签 |
| 25% | **少样本学习与反馈更新** | “拿到16个实验结果后，重排未测候选，说明策略变化。” | 上述证据、16条`mutation→fitness`反馈、未测列表 |
| 15% | 盲测、误差分析与报告 | “比较两种方法选出的前10个，检查收益来自哪里。” | 固定划分、预测文件、独立保管的标签、运行记录 |

## 3. 实验研发科学家 / 研究助理：把候选变成可信的测量

| 时间 | 任务 / 场景 | 代表性 query | input |
|---:|---|---|---|
| 30% | 构建、表达与样品准备 | “检查构建单的序列与突变编号是否一致。” | 参考序列、设计序列、引物/构建单、样品ID |
| 35% | 建立测定与执行筛选 | “给这批样品安排重复、阳性/阴性对照和板位。” | 样品列表、读出指标、板规格、对照、操作约束 |
| 20% | 原始读出QC与归一化 | “标出异常孔，按既定规则归一化；不要直接删除失败样本。” | 原始读数、plate map、对照、批次、重复ID |
| 15% | 记录、复核与回传反馈 | “输出可被计算团队直接读取的结果，保留测量不确定性。” | 样品ID、归一化结果、重复统计、QC标记 |

## 4. 实验自动化 / 数据平台工程师：保证循环能持续运转

| 时间 | 任务 / 场景 | 代表性 query | input |
|---:|---|---|---|
| 35% | 自动化流程开发与故障排查 | “定位这次移液流程中断的位置，给出可验证的恢复方案。” | 设备日志、流程版本、板位状态、故障码 |
| 30% | 样品与数据追踪、系统集成 | “对齐LIMS样品、构建序列与实验结果，找出重复或缺失ID。” | LIMS导出、序列版本、plate map、结果表 |
| 20% | 计算工作流与工具维护 | “让结构/MSA处理失败时明确报错，而不是返回空证据。” | 工具接口、失败文件、日志、数据契约 |
| 15% | 监控、审计与团队支持 | “复核这份排序由哪个模型、哪些输入和反馈生成。” | 请求哈希、程序版本、调用记录、预测文件 |

## 本项目切入哪里？

切入计算岗位中“预测与反馈更新”，同时减少蛋白工程科学家解释候选、平台工程师对齐证据的负担。

**零样本**是冷启动：还没有本项目测量时，用进化与结构证据决定先测什么。**少样本**是反馈学习：把实验室刚返回的小批结果用于修正排序。二者服务同一个定向进化循环；预测是循环中的决策依据，实验才决定候选是否真的更好。

蛋白药物优化还需要结合、表达、稳定性、免疫原性等多种读出。本仓库用一个功能读出的公开回顾性案例验证关键环节，不把它等同于完整药物研发。
